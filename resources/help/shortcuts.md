# Keyboard & Mouse

## Viewport

| Action | Input |
|---|---|
| Orbit | Middle drag, or Alt + left drag |
| Pan | Right drag, or Shift + middle drag |
| Zoom (at the cursor) | Mouse wheel |
| Select a part | Left click |
| Move a part | Drag an arrow of the translate gizmo |
| Fit everything in view | F |
| Front, Top or Side view | The buttons at the top of the viewport, or click a face of the view cube |
| Cancel axis picking | Esc |
| Move a robot tool by its joints (inverse kinematics) | Turn **IK** on, then drag the tool's gizmo |
| Look inside an assembly | **Section**, then *Cut the model* |
| Measure a distance or angle | M, then click two points (snaps to hole centres, bore axes, corners); Esc ends |
| Assemble parts (flush faces, aligned axes, bolts in holes) | A, then click the part to move and where it goes; Enter keeps the mate, Esc steps back |

## Application

| Action | Shortcut |
|---|---|
| Help | F1 |
| New, Open, Save project | Ctrl+N, Ctrl+O, Ctrl+S |
| Undo, Redo | Ctrl+Z, Ctrl+Shift+Z |
| Show or hide the Automation panel | Ctrl+J |
| Robot Builder | Ctrl+Shift+R |
| Play / Pause | Space |
| Step one scan | F10 |
| Delete the selected part | Delete |
| Duplicate the selected part, with its children, joints and actuators | Ctrl+D |
| Hide the selected part (or every part picked in the Hierarchy), or show it again | Alt+V |
| Show every hidden part | Alt+Shift+V |
| Rename in the hierarchy | F2, or double-click |
