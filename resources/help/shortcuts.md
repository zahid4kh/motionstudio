# Keyboard & Mouse

## Viewport

| Action | Input |
|---|---|
| Orbit | Middle drag, or Alt + left drag |
| Pan | Right drag, or Shift + middle drag |
| Zoom (at the cursor) | Mouse wheel |
| Select a part | Left click |
| Move a part | Drag an arrow of the translate gizmo |
| Fit everything in view | F |
| Front, Top or Side view | The buttons at the top of the viewport, or click a face of the view cube |
| Cancel axis picking | Esc |

## Application

| Action | Shortcut |
|---|---|
| Help | F1 |
| New, Open, Save project | Ctrl+N, Ctrl+O, Ctrl+S |
| Undo, Redo | Ctrl+Z, Ctrl+Shift+Z |
| Show or hide the Automation panel | Ctrl+J |
| Play / Pause | Space |
| Step one scan | F10 |
| Delete the selected part | Delete |
| Duplicate the selected part, with its children, joints and actuators | Ctrl+D |
| Rename in the hierarchy | F2, or double-click |
